# FixIT v1.1 - changelog roboczy

Ten dokument zbiera zmiany przygotowane na branchu `v-1.1`.
9 czerwca 2026 branch zostal zmergowany do `main` i wdrozony na Railway.

## Zmiany

### 2026-08-04 - DayLog dla panelu administracyjnego

- Dodano wspólną stronę `/admin/daylog` dla agentów i administratorów.
- Wpis zawiera datę/godzinę zdarzenia, osobę kontaktową, temat, opis oraz autora.
- Dodano trwały model Prisma/PostgreSQL `DayLogEntry` i migrację `20260804120000_add_daylog`.
- Dodano eksport wpisów do pliku Excel (`.xlsx`) oraz link DayLog w nawigacji admina.
- Zmiana została wdrożona na Railway z commita `b6211bf`.

### 2026-08-05 - Edycja i usuwanie wpisów DayLog

- Dodano edycję daty/godziny, osoby kontaktowej, tematu i opisu istniejącego wpisu.
- Dodano usuwanie wpisu z potwierdzeniem po stronie interfejsu.
- Dodano walidację uprawnień oraz testy dla obu operacji w JSON-store i Prisma data-store.

### 2026-08-10 - Tworzenie zgłoszenia z DayLog

- Dodano przycisk `Utwórz zgłoszenie` przy niepowiązanym wpisie DayLog.
- Formularz nowego zgłoszenia uzupełnia temat, opis i kontakt na podstawie wpisu; kategorię, lokalizację i pilność wybiera użytkownik.
- Po utworzeniu wpis przechowuje trwałe powiązanie i pokazuje link z numerem zgłoszenia.
- Powiązanie jest zapisywane atomowo w providerze Prisma/PostgreSQL i JSON, co zabezpiecza przed utworzeniem dwóch zgłoszeń z jednego wpisu.
- Dodano migrację `20260810120000_link_daylog_ticket`, kontrolę uprawnień oraz testy kontraktu i idempotencji.
- Walidacja: `npm run typecheck`, `npm run lint`, `npm run test` — 162 passed, 1 skipped; schemat Prisma jest poprawny.

### 2026-08-10 - Grafik tygodniowy z dyżurami

- Dodano stronę `/admin/schedule` z pełnym tygodniem od poniedziałku do niedzieli oraz widokiem mobilnym.
- Administrator może dodawać, edytować i usuwać zadania, oznaczać dyżury oraz kopiować poprzedni tydzień do pustego tygodnia.
- Agent widzi cały grafik i może zmieniać wykonanie wyłącznie własnych zadań.
- Interfejs ostrzega o każdym dniu bez wyznaczonego dyżuru i wyróżnia weekend.
- Uczestnicy nie są zapisani na sztywno: aktywne konta `AGENT` i `ADMIN` włącza się do grafiku w panelu użytkowników.
- Dodano modele `ScheduleTask` i `ScheduleDuty`, migrację `20260810160000_add_weekly_schedule` oraz obsługę Prisma/PostgreSQL i JSON.
- Kopiowanie tygodnia jest transakcyjne, resetuje wykonanie zadań i nie nadpisuje istniejącego grafiku.
- Walidacja: `npm run typecheck`, `npm run lint`, `npm run test` — 172 passed, 1 skipped; schemat Prisma jest poprawny.

### 2026-08-10 - Aktualna godzina DayLog i automatyczne odświeżanie

- Godzina szybkiego wpisu DayLog jest ustawiana podczas otwierania formularza, a nie podczas wejścia na stronę.
- Rozpoczęty szkic wpisu nie jest nadpisywany po zamknięciu i ponownym otwarciu formularza.
- Ekrany operacyjne odświeżają dane co minutę oraz po powrocie do karty, jeśli użytkownik nie pracuje w formularzu.
- Na produkcji wyłączono Railway Serverless dla aplikacji i PostgreSQL, eliminując cold starty oraz wyścig migracji z wybudzaniem bazy.
- Walidacja: `npm run typecheck`, `npm run lint`, `npm run test` — 173 passed, 1 skipped; build produkcyjny jest poprawny.
