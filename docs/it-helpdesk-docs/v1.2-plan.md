# FixIT v1.2 - plan wydania

Planowane wydanie: koniec sierpnia 2026.

Branch roboczy: `codex/v1.2`. Produkcyjny `main` pozostaje stabilny do czasu zakończenia regresji i kontrolowanego merge.

## Zasady pracy

- Każda logiczna zmiana ma osobny, mały commit.
- Nie zmieniamy zachowania produkcyjnego bez testu lub opisanej regresji ręcznej.
- Nie uruchamiamy automatycznych aktualizacji zależności z opcją `--force`.
- Przed merge wymagane są: lint, typecheck, testy jednostkowe, testy z PostgreSQL, E2E, build produkcyjny i smoke test na Railway.
- Wydanie musi mieć plan wycofania oraz potwierdzony backup bazy danych.
