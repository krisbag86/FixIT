# FixIT v1.2 - changelog roboczy

Wydanie v1.2 zostało zmergowane do `main` (PR #9). Wdrożenie na produkcję i smoke test pozostają do wykonania.

## Unreleased

### 2026-08-17 - testy integracyjne PostgreSQL i zamknięcie audytu

- `npm audit --omit=dev` i pełny `npm audit` są czyste (0 podatności); zamknięto pozycje planu dotyczące Sharp, ExcelJS i UUID.
- Dodano testy integracyjne bazy PostgreSQL (`tests/prisma-integration.test.ts`) dla runtime Prisma `lib/data-store.ts`: numeracja ticketów, cykl życia statusów, ukrycie hashów haseł, audyt admina, widoczność notatek wewnętrznych, powiązanie DayLog→ticket z idempotencją oraz grafik tygodniowy.
- Testy integracyjne są pomijane bez `DATABASE_URL` i uruchamiane w CI na usłudze Postgres 16 (migracje + seed przed testami). Lokalnie: `docker compose up postgres` + `npm run db:migrate:deploy` + `npm run db:seed`.
- Poprawiono parzystość runtime Prisma z JSON-store: `resolvedAt`/`closedAt`/`dueAt` zwracają `null` (zamiast `undefined`) dla niezapisanych znaczników, zgodnie z kontraktem `Ticket`.
- Poprawiono ładowanie Google Fonts: `@import` w `app/globals.css` przeniesiony na początek pliku (wcześniej ignorowany przez przeglądarki) oraz rozszerzono CSP w `middleware.ts` o `fonts.googleapis.com`/`fonts.gstatic.com`.
- Zwiększono liczbę testów: 199 passed / 0 skipped z PostgreSQL, 193 passed / 1 skipped bez bazy.
- Podniesiono wersję pakietu do `1.2.0`.

### 2026-08-12 - porządki produkcyjne

- Rozpoczęto porządkowanie martwego kodu i zbędnych eksportów.
- Usunięto nieużywany komponent skeletonów oraz zduplikowany plik blokady migracji Prisma.
- Usunięto nieużywaną zmienną `COOKIE_SECRET` z przykładowej konfiguracji i README.
- Dodano reguły ESLint dla Next.js i Core Web Vitals.
- Poprawiono wewnętrzną nawigację czyszczenia filtrów na komponent `next/link`.
- Zaktualizowano Next.js 15 do najnowszej poprawki 15.5.23 oraz Nodemailer do 9.0.5.
- Zaktualizowano podatne wersje PostCSS i zależności pośrednich bez użycia `npm audit fix --force`.
- Liczbę zgłoszeń `npm audit --omit=dev` zmniejszono z 12 do 4; pozostałe wymagają osobnej migracji Next.js 16 i decyzji dotyczącej ExcelJS/UUID.
